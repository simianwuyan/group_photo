# AI 辅助多人合影 —— 多帧优势合并（在线 Demo）

连拍多帧 → 逐人评分（睁眼/清晰度/亮度/表情/视线）→ 选基准底片 → 只替换状态不佳者 → 无缝融合。

设计三原则：
1. **基准底片**：背景与姿态 90% 来自原图，只动有问题的脸 —— 无"AI 感"；
2. **最小替换**：只替换不达标的人，替换越少痕迹越小；
3. **可解释**：每个人为什么被换、换成哪一帧、前后分数多少，全部可见。

## 在线体验

- **多帧合并**：上传连拍多帧（手机连拍模式拍摄，导出 JPG）→ 成片 + 标注图 + 逐人报告表
- **合成演示（路演用）**：上传一张合影 → 自动生成含闭眼的连拍 → 展示修复效果

本 Space 仅演示算法链路；PC 摄像头连拍 / 手机连拍服务属于端侧功能，
见 GitHub 仓库（全流程可离线，人脸数据不出设备）。

## 技术栈

纯 Python 端侧推理：MediaPipe FaceLandmarker（478 点关键点）+ OpenCV + Gradio，
零训练、零云 API、不上传数据（云端 Space 仅在你上传时临时处理本次请求）。
